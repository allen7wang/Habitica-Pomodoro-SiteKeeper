# v2.1.4 — 并发响应与账号切换修复（macOS）

2026-11-07 · 主程序与今日任务小组件 **2.1.4 / build 18**

## 本次修复

- **错误提示顺序**：较慢的成功响应不再清除刚出现的网络、服务器或响应解析错误；较旧的失败也不会覆盖已经报告的新错误。重新发起且成功的刷新仍可清除旧错误。
- **认证状态**：较早发起的角色请求即使稍后成功，也不能撤销较新的 HTTP 401 认证失败。
- **账号切换与重新连接**：切换账号、Token、连接开关或有效 API 地址后，旧读取不再被复用，旧数据和错误不能提交到新连接；切回同一账号也会重新读取。普通偏好修改和等价 API 地址不会打断正常读取。
- **同步过程中切换账号**：两次读取组成的 Top3 同步使用同一次连接；反馈或角色数据发布时发生账号切换，会停止旧请求派发并撤去旧状态。
- **保留写入与限额保护**：已发送写操作继续返回真实结果，不会自动重放；限额和服务器冷却仍按原账号保存，切换连接不能绕过。

原有任务、专注历史和设置继续使用，不更改存储格式。旧版遗留且无法确认结果的创建标记仍保留，避免重复上传。
