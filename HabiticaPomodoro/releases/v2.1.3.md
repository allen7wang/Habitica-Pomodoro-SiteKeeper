# v2.1.3 — 上传重试与列表加载修复（macOS）

2026-11-07 · 主程序与今日任务小组件 **2.1.3 / build 17**

## 本次修复

- **新建任务恢复上传**：请求尚未发送就被本地额度或取消阻止，或收到 HTTP 401/429 明确拒绝时，不再把任务永久留在“创建结果不明”的状态。本机任务继续保留；修正凭据或冷却结束后，手动同步可重新上传。
- **删除与账号切换**：上述创建请求返回期间，即使任务被删除或切换账号，也只清理原账号、原任务对应的创建标记，避免阻塞同日同分类的新任务。
- **异常列表保留旧数据**：习惯、每日任务收到错误响应、无效 JSON、缺少必要字段（ID/标题）或重复 ID 时，保留当前账号上次加载的列表。合法空列表仍会正常显示为空。
- **各请求独立判断结果**：某次列表加载成功时，不再因为另一个请求的共享错误提示而丢弃它的数据。

已发出的创建若因断网、超时、服务异常或成功响应缺少 ID 而无法确认结果，仍保留核对标记，避免重复创建；本版不会自动重放这些请求，也不会自动清除旧版本遗留且无法确认结果的标记。

## 验证与边界

- Apple 离线回归 **11 个用例 / 173 项断言全部通过**，覆盖上传拒绝后的实际重试、派发前/后的取消与网络失败、删除/账号切换、异常列表和既有计时/存储回归；所有源码快照与最终代码一致。
- 修正限流测试的慢响应路径匹配，并验证成功角色数据确实被采用；整数上界测试允许浮点舍入后的两种安全提示，同时严格检查冷却期间不再派发请求。
- macOS 主程序与小组件的 Apple Silicon / Intel 双架构构建、iOS 共享代码兼容编译通过。
- DMG 挂载核对主程序与小组件均为 2.1.3/build 17，签名与 SHA-256 校验通过，包内不含个人配置或运行数据。
- 本轮未使用真实 Habitica 账号进行在线操作，也未进行真机音频或 iCloud 跨设备验收。各功能仍共用错误提示，其他成功请求可能更新提示；列表数据保留不依赖该提示。

## 安装

下载 **HabiticaPomodoro-2.1.3-Installer.dmg**，先结束当前番茄并退出旧应用，再打开安装包，将应用拖入 Applications 替换旧版。现有设置、任务及历史记录继续使用；若系统重新询问，请允许应用访问「文稿」。

主程序要求 macOS 13.0+，小组件要求 macOS 14.0+；均支持 Apple Silicon 与 Intel。安装包使用 ad-hoc 签名。iOS / Android 的发行版本仍为 v1.2.5，本次未提供移动端更新包。
