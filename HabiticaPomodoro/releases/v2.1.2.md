# v2.1.2 — Habitica 同步稳定性更新（macOS）

2026-11-07 · 主程序与今日任务小组件 **2.1.2 / build 16**

## 本次修复

- Habitica 各功能共享请求额度，同一账号/API 地址在滚动 60 秒内最多发送 24 次请求，并遵守服务器的剩余额度与冷却要求。
- 遇到限流时提示等待，保留待同步任务及删除进度。冷却结束后可手动刷新继续；创建任务、打分等操作不会自动重放。
- 已获服务器确认的删除不再反复发送，同时保留删除记录，防止旧响应重新导入任务。
- 合并相同的读取请求，写入后重新读取验证，减少无效请求。
- 修复异常大的服务器等待时长可能导致应用崩溃的问题。

## 从 v1.2.7 升级还将获得

- **专注复盘**：查看连续 7、30、90 天及更早的日期，按天回看番茄次数、专注时长、时间块与种植记录，导出当前范围的 CSV。
- **跨天未完成任务**：集中查看昨天及更早未完成的任务，删除或转到今天的原分类；分类满额时任务保留在列表。
- **任务页顺序**：今天、昨天放在上方，未完成任务放在下方；效率工作台保留今天/昨天并排。
- **启动体验**：先显示窗口，再后台读取记录；读取失败可重试，复盘默认选中最近有记录的一天。

## 安装

下载 **HabiticaPomodoro-2.1.2-Installer.dmg**，先结束当前番茄并退出旧应用，再打开安装包，将应用拖入 Applications 替换旧版。现有设置、任务及历史记录继续使用；若系统重新询问，请允许应用访问「文稿」。

支持 Apple Silicon 与 Intel。主程序要求 macOS 13.0+，小组件要求 macOS 14.0+。安装包使用 ad-hoc 签名；首次打开如被系统拦截，可在 Finder 中右键应用选择“打开”。iOS / Android 发行版本仍为 v1.2.5，本次未提供移动端更新包。
