# 清新原生视觉探索

这是视觉方向确认用的可交互原型，不是已经完成改造或安装的应用。正式实现继续使用 SwiftUI / Compose；本目录不接生产数据。

## 打开

用浏览器打开本目录 `index.html`，在顶部切换三个方向；每个子目录也可独立打开。全部文件内嵌样式与脚本，无网络、字体或第三方依赖。

| 方向 | 布局与取舍 |
|---|---|
| 清新原生（推荐） | 紧凑五 Tab、单一主操作、扁平时间块与声音条。最接近现有使用习惯。 |
| 留白花园 | 主操作居中、下方导航、低密度。更安静，但同时查看任务需切页。 |
| 效率工作台 | 侧栏、专注与任务并排。适合桌面大窗口，窄屏回到单列。 |

## 可体验

开始 / 暂停 / 重置确认、五页导航、示例任务完成与添加、习惯 +/-、每日任务、角色页、时间块入口、声音设置、深浅色。快捷键 Space 和 ⌘⇧P 控制示例计时；⌘1–5 切页。

## 安全边界

- 使用明确标注的示例数据，不读取账号、本地任务或云文件，不播放声音、不发通知。
- 没有改动生产 Swift/Kotlin、版本、安装内容或真实数据，也没有加入付费/订阅。
- 视觉预览不等于原生可访问性、真机、真实 iCloud/Habitica/音频链路验收；商业授权和上架要求也不在此预览中完成。
- 用户选定方向后再按 Mac → iOS → Android 落地，不把三种布局作为永久主题加入正式应用。
