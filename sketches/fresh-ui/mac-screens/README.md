# macOS 三套界面截图（v1.2.6）

截图来自 DEBUG 验证构建，数据目录指向隔离的合成数据（`POMODORO_ISOLATED_DIR`），不是用户的真实账号或任务。

| 文件 | 内容 |
|---|---|
| `01-mint.png` | 清新原生：顶部五 Tab、圆环计时、时间块与今日要事 |
| `02-garden.png` | 留白花园：居中专注区、底部导航 |
| `03-studio.png` | 效率工作台：左侧栏 + 专注/任务双栏（820×540） |
| `04-appearance-settings.png` | 设置 → 外观：三套风格卡片与色板 |

切换入口：主窗口右上角调色板按钮，或 设置 → 外观。选择保存在本机；窗口会随风格调整尺寸。
